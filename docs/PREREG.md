# 사전등록 — 심은 정답 시뮬레이션 비교 (E2)

작성: 2026-11-02 (비교 실행 전). 이 문서 이후 세계 파라미터·판정 규칙을 바꾸면 아래 "변경 기록"에 남긴다.
버그 수정을 위한 1~2 시드 시험 실행은 허용하고, 그 사실도 기록한다.

## 질문
누적 설문을 매번 그대로 돌리는 방식, 같은 학습기에 문항만 고정한 방식, 문항이 스스로 진화하는 Q-Loop 중
8개 분기 동안 **액션으로 실제 만든 순이익(매출 증가 − 액션 비용)** 이 어느 쪽이 큰가.

## 세계 (qloop/world.py, 에이전트는 import 하지 않음)
- 세그먼트 3개: B2B 사진관·인화점 파트너 400곳, B2B 산업재 고객(LTO·프리스케일) 160곳, B2C 인스탁스·몰 회원 4,000명.
- 고객마다 이진 잠재 니즈(세그먼트별 3~5개, 유병률 0.20~0.35). 분기마다 10% 확률로 다시 뽑힘.
- **누적 문항이 재지 못하는 니즈**를 일부러 하나씩 둠: 사진관 '재고·결품', 산업재 '납기', B2C '필름 가격 부담'.
  B2C 에는 4분기부터 '포토카드 굿즈 수요'가 새로 생김(시장 변화).
- 누적 문항(12/8/14개)에는 신호 문항, 약한 문항, 중복 문항, 매출 수준과만 엮인 만족도 문항, 아무것도 안 재는 문항이 섞여 있음.
- 액션은 니즈가 있는 고객에게만 효과(분기 매출의 6~18%), 비용은 고객당 고정.
- 분기 매출 잡음 = 규모의 12%. 응답률 = 8문항 기준 65%/55%/22%, 문항 1개당 3~3.5% 지수 감쇠(가정).
- 개방형 응답: 니즈가 있는 응답자의 75%가 그 니즈를 서술, 나머지는 무관한 말. 문장의 약 30%는 사전에 안 걸림.
- 정책 비교는 공통 난수로 함: 같은 시드면 고객·니즈·잡음·응답 성향이 정책과 무관하게 같음.

## 정책
1. 기존 방식: 누적 문항 전부, 매출 수준과 상관이 큰 상위 5문항 중 점수가 가장 나쁜(4점 이상) 문항에 사람이 붙인 액션. 무응답자는 액션 없음.
2. 학습기만: 상호작용 회귀 + 무작위 대조군 15%, 누적 문항 전부 고정.
3. Q-Loop: 2와 같은 학습기 + 진화(파일럿 2분기 뒤 문항 상한 8/7/7, 결정 기여도 |t|<1.0 이 2회 연속이면 폐기,
   새 문항 |t|≥2.0 이 2회 연속이면 승격, 회차당 폐기·추가 각 2개 상한, 개방형 주제 6% 이상이면 새 문항 후보,
   응답 상관 0.7 이상 중복 정리, 폐기 4분기 뒤 재시험, 대조군 기준 이득 2SE 하락 시 롤백).

## 지표
- **주지표**: 8분기 누적 순이익의 오라클 대비 포착률(세 세그먼트 합). 오라클 = 진짜 니즈를 알 때의 최선 액션.
- 보조: 세그먼트별 포착률, 평균 문항 수, 응답률, 물은 문항 중 실제 신호 문항 비율, 숨은 니즈를 재는 문항이 처음 들어간 분기, 롤백 횟수.
- 시드 20개. 정책 간 차이는 시드별 짝 차이의 평균과 부트스트랩 95% 구간.
- 민감도: 응답률 감쇠를 0으로 둔 세계(설문이 길어도 응답률이 안 떨어지는 경우)에서도 같은 비교.

## 해석 규칙(미리 정함)
- Q-Loop − 학습기만 의 차이 = 진화의 기여. 학습기만 − 기존 방식 의 차이 = 무작위 대조군·상호작용 학습의 기여.
- 감쇠 0 세계에서 Q-Loop 우위가 사라지면 "우위는 짧은 설문의 응답률 효과뿐"이라고 쓴다.
- 이 세계는 내가 만든 것이므로 결과는 "메커니즘이 설계대로 작동한다"는 증거이지, 실제 후지필름 매출 효과의 크기가 아니다.

  ③ 문항 ID 접두어가 두 B2B 세그먼트에서 겹침 → 세그먼트별 접두어.
  ④ 지표 '숨은 니즈를 재는 문항' 이 신호가 약한 문항(|적재|<0.5)까지 세던 문제 → 신호 문항만.
  ⑤ 폐기된 누적 문항 재시험 조건이 주제 태깅 뒤 막히던 문제 → 누적 문항이면 재시험 대상.
